Reading the counts

Each decision number counts once within a departure and filter. A decision can cover several issues or remedies, producing several order rows. A dismissal is an order statement in the source. The summaries do not identify passenger-specific circumstances behind different outcomes.

Departures are grouped by the carrier, flight number, ticket date and airport pair reported by the CTA. Routes with different airport codes appear separately. A curated collection or filtered file covers only the records it contains.
